# Viewport nodes

Use the Viewport nodes to set the size of a render target surface onto which Kanzi projects content.

Kanzi has these Viewport nodes:

- Use the Viewport 2D node to render both 2D nodes, such as Image or Button 2D, and a Scene, which is a 3D node.

See Using the Viewport 2D node.
- Use the Viewport 3D node to add 2D nodes to a 3D scene.

See Using the Viewport 3D node.
