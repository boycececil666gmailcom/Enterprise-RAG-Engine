# Tutorial: Materials and textures

In this tutorial you learn the basics of working with materials and textures in Kanzi Studio to get the rendering result you want. You learn about different material types, textures, and how to create and work with them. You also learn how to adjust material settings to achieve different look and feel of your rendered objects.

In this tutorial you create and define the materials and textures for a car model.

This image shows the result of the tutorial.

This tutorial assumes that you understand the basics of working with Kanzi Studio. The best entry points for getting familiar with Kanzi Studio are:

- Tutorial: Getting started with Kanzi Studio
- Tutorial: Create a simple in-vehicle infotainment application
