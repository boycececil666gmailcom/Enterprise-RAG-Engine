# Transferring your license

You can transfer an activated Kanzi Studio license from one computer to another.

Kanzi Enterprise license is locked to the computer on which the license was activated.

To transfer the license you first have to release it from the computer where you activated the license, and then activate it on another computer.

When you want to use Kanzi Studio both in Boot Camp and in a virtual machine, such as VMWare Fusion of Parallels Desktop, you have to release the Kanzi Studio license before you switch the working environment.

For example, if you use Kanzi Studio in Boot Camp and then want to use Kanzi Studio in a virtual machine, release the Kanzi Studio license while you are still running it in Boot Camp and then activate the same Kanzi Studio license when you start Kanzi Studio in the virtual machine.

To transfer your license:

1.

In Kanzi Studio select Help > Manage Licenses.

Kanzi Studio License Manager window opens.
2.

Select Release this license and click Next.
3.

If required, set up proxy, and click Release.

  - If the license release is successful, click OK to close Kanzi Studio.
  - If the license release is not successful, the License Manager displays a message saying what went wrong.

4.

Activate the released license on another computer. See Using a product key to activate Kanzi Studio.
