# Kanzi Studio license management


Kanzi Studio is protected against unauthorized use with a licensing system that prevents the application from starting without a valid license or when the trial period expires. Kanzi Engine provides functionality based on the license information embedded in the Kanzi kzb file created by Kanzi Studio.

Kanzi Enterprise license is locked to the computer on which the license was activated.

You can transfer a Kanzi Enterprise license to another computer by releasing it first. See Transferring your license.

The following Kanzi licenses are available:

- Kanzi Trial license is meant for evaluating Kanzi. During the evaluation you can submit technical support requests at [evaluations@rightware.com](mailto:evaluations%40rightware.com).
- Kanzi Enterprise license is intended for production projects. Enterprise license is for design houses, original equipment manufacturers, original design manufacturers and tier-one manufacturers involved in professional product development in mobile, automotive, and other industries. Enterprise license grants you the access to extensive technical support, for example, for hardware platform-specific Kanzi Engine optimizations. Owners of Enterprise licenses can submit technical support requests using the Kanzi Support Portal. See Technical support.


On a single computer, you can use only one type of Kanzi license at a time.

Activating your Kanzi Studio license depends on the type of the license that you purchased:

- Using a product key to activate Kanzi Studio
- Using a dongle license to activate Kanzi Studio
- Using a floating license
- Using a license file to activate Kanzi Studio
