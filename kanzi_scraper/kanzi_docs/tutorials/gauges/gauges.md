# Tutorial: Create gauges


In this tutorial you learn how to control the position of gauge needles with custom properties. You connect the position of each needle to the value of a property in Kanzi Studio using bindings.

Complete the tutorial by watching the video, or by following the written instructions.

This tutorial assumes that you understand the basics of working with Kanzi Studio. The best entry points for getting familiar with Kanzi Studio are:

- Tutorial: Getting started with Kanzi Studio
- Tutorial: Create a simple in-vehicle infotainment application


Start with the tutorial
