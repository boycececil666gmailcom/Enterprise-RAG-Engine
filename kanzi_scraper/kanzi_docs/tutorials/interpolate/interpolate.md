# Tutorial: Interpolate property values


In this tutorial you learn how to dynamically set the target value for a property and interpolate the current value to the target value over time.

You learn how to use the Property Target Interpolator to animate the rotation of a compass dial and the Interpolation Completed trigger to change the compass background color when the interpolation completes.

This video shows the result of the tutorial.

This tutorial assumes that you understand the basics of working with Kanzi Studio. The best entry points for getting familiar with Kanzi Studio are:

- Tutorial: Getting started with Kanzi Studio
- Tutorial: Create a simple in-vehicle infotainment application
