# Coin example


This example demonstrates the use of Kanzi physically-based materials. See Physically-based material properties.
## Getting the example


To get the example, in the Kanzi Studio Quick Start window, click Examples. Next to the Coin example, click .

Kanzi Studio downloads the example to the `<KanziWorkspace>/Examples/Coin` directory.
## Running the example


Open the example in Kanzi Studio.
